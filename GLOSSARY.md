# XP Skills

Agent skills for a single-loop workflow, grill then implement in one context, inspired by Extreme Programming and built on top of Matt Pocock's skills (not a fork of them).

## Language

**Story**:
A change that goes from idea to pull request inside a single context window, through one grill and one implement.
_Avoid_: Feature, spec, ticket, iteration, slice

**Card**:
A one-line note of a Story not yet grilled, with no acceptance criteria and no decisions.
_Avoid_: Ticket, issue, backlog item
